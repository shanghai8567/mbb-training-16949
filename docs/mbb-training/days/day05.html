B核心概念与理论框架

p 值不是 H0 为真的概率。

【汽车电子 · Analyze — 缺陷-过程矩阵 + ADAS FCT】用缺陷-过程矩阵：行=Eth_FAIL/CAN_FAIL/Checksum_FAIL；列=离线烧录/SMT/手插/装配。卡方或对比检验比较「错版批次 vs 正常批次」FCT；须对比 X-Ray SL 全检期与 MP 抽检期的空洞 Pareto。

专业类比 — ANOVA 显著后像发现「有差异」，Tukey 才告诉「谁和谁差」。

先 Levene/正态；再选 t/ANOVA/非参数。

关键公式
α = P(拒绝H₀ | H₀为真)

ADAS DCU-A

Eth 失败：是错版批次，还是炉温 Profile？

Pareto 显示 Eth_FAIL 占 62%。BB 想「炉温调高试试」。MBB 拉出列联表：错版批次 Eth 不良 8.2%，正常批次 0.4%；卡方 p=0.003。但 Champion 说：「8.2% 才差 7.8 个点，值得停线吗？」

BB我把炉温 +5℃ 试产？
MBB先证明不是错版——列联表 + 效应量，别只甩 p 值。
Champion统计显著就行了吧？
MBB还要算比例差/OR 与 95% CI；若年化百万片，0.3% 也值钱。

**Analyze** 用缺陷矩阵链到四段工艺。报告须含：**前提**（独立批次？期望频数？）、**p 值**、**效应量**（比例差/OR）、**业务翻译**。切忌 HU FCT-03 混入 ADAS 故事。

专业加深（P0 / P1 / P2）
  • **P0 · 效应量**：p&lt;0.05 只说明「有证据」；Champion 看 **差多少** —— 例：错版批次 Eth 不良率差 7.8% + 95% CI。
  • **P0 · 前提**：列联表期望频数&lt;5 时考虑 Fisher 精确检验；批次非独立则夸大显著性。
  • **P1 · SL→MP X-Ray**：Analyze 必须标注 **X-Ray 切换日**；切换前后空洞 Pareto 不可合并。
  • **P2 · 检验功效**：样本量过小会「检不出」错版效应 —— Analyze 前用功效分析定最小 n（与模块 06 DOE 功率分析同源）。
  • **P2 · 非正态空洞**：X-Ray 空洞% 非正态勿硬报 Cpk；用变换或 Weibull + 单边规格，并写明分布假设。
分析/评审前检查
  • H0/H1 与检验匹配
  • 报告有效应量或比例差
  • X-Ray 阶段已分层
Pareto列联表/卡方效应量/OR5Why

E课堂练习（先作答再对答案）

  • E1. 填缺陷-过程矩阵（至少 3 行缺陷 × 4 列工艺）
    参考答案

    要点：缺陷×工艺矩阵：行 Eth_FAIL/Checksum_FAIL/U12_void；列 离线烧录/SMT/手插/FCT；格内填 n 或 %。

    Analyze 门核心证据。

  • E2. 用 fct-yield.csv 说明如何按 SOC_FW 分层
    参考答案

    要点：fct-yield.csv：按 SOC_FW/Program_ID 分层，禁止 DCU-B 与 ADAS 合并；列联或 2 样本比较版本间通过率。

    混杂版本会导致假显著。

  • E3. 解释 p=0.03 但 Eth 改善 0.05% 是否实施
    参考答案

    要点：p=0.03 但 Eth 仅改善 0.05%：统计显著未必有商业意义；须算年化效益 vs 换钢网/停线成本再决策。

    MBB 常在此打回贸然 Improve。

  • E4. 选 t 还是 Mann-Whitney
    参考答案

    要点：连续近似正态、方差齐 → 2 样本 t；偏态或 n 小 → Mann-Whitney；比例 → 卡方/双比例。

    先 Levene/正态再选检验。

  • E5. 写 H0/H1
    参考答案

    要点：H0：两批 Eth 通过率无差异；H1：有差异（或指定方向）。α=0.05，报告差值 CI 与百分点。

    H0 永远写「无差异/无效应」，不写「有改善」。
