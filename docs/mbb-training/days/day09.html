    B核心概念与理论框架

    RSM 找山坡最平缓平台，不单峰冒险。

    【汽车电子 · RSM — SPI/空洞稳健区】确认运行：在 Profile#ADAS-04 稳健区内试产 3 批，每批离线烧录 0 错版、SL 期 X-Ray 全检、FCT≥99.5%。

    专业类比 — 炒菜火候曲面：甜区比单点最高温更安全。

    曲率显著才 RSM；外推禁止。

    E课堂练习（先作答再对答案）

    • E1. 写 3 批 Safe Launch 判定标准
      参考答案

      要点：Safe Launch 3 批：① U12 空洞≤SL 目标 ② FCT Eth≥99.5% ③ 无新增 Fail_code Top3；任一批不达标则停扩产。

      CSR 常规定 3–5 批。

    • E2. 说明外推禁止的边界
      参考答案

      要点：外推禁止：Minitab 最优点在 DOE 立方体外 → 须 3 点确认运行（含预测区间覆盖），ECN 前不得量产。

      曲率不显著不必上 RSM。

    • E3. 何时用 RSM
      参考答案

      要点：RSM/CCD：曲率显著、因子≥2、需找稳健平台时用；筛选阶段用 2^(k-p) 即可。

      ADAS Profile 优化典型场景。

    • E4. 写确认运行表
      参考答案

      要点：确认运行表：3 点（预测最优、最优±Δ）、每点 n≥3 板、随机序、响应空洞% 与 FCT 抽检。

      附预测 vs 实测对比表。
