B核心概念与理论框架

生锈卷尺量身高 — MSA 是尺子是否靠谱。

【汽车电子 · MSA — SPI / 烧录 / BGA 空洞 / FCT 探针】SPI %GRR 评估「焊膏体积」测量；烧录 Checksum 比对设备做属性 GR&R；BGA 空洞 AOI 与 X-Ray 一致性研究；FCT 探针接触为计数型 GRR。%R&R>30% 时禁止仅报 SPI Cpk 给客户。

专业类比 — Cp 是车道宽度；Cpk 是车是否压线。

%RR<10% 可接受；>30% 停报 Cpk。

关键公式
Cp=(USL−LSL)/(6σwithin)
关键公式
Cpk=min[(USL−μ)/3σ,(μ−LSL)/3σ]

本课主线：MSA — SPI / 烧录 / BGA 空洞 / FCT 探针

GRR=28% 的 SPI，还能开控制限吗？

三台 SPI 比对，%GRR=28%。工艺想「先上线，以后再改善」。MBB 翻开 AIAG MSA-4 判据：>30% 不可接受，10–30% 边缘。「边缘不是通行证，是改进项目。」隔壁 AOI 工位，目检员甲丙对同一 BGA 空洞判不一致——Kappa 仅 0.55。

工艺工程师28% 差不多能用吧？
MBB边缘区要立项改进，不是口头放行。
AOI 主管目检靠老师傅，还要做 MSA 吗？
MBB要——属性量测用 Kappa/一致性，和 SPI 的 GRR 不是一张表。

**MSA 是 Measure 阶段的门禁**：计量 CTQ 用 %GRR、ndc、偏倚；**属性判定**（AOI 过/不过、FCT Pass/Fail 人工复判）用 **Kappa/一致性**。汽车电子陷阱：座舱与 ADAS 共用测点却不评审；SL 全检期数据混入 MP 抽检期。

专业加深（P0 / P1）
  • **P0 · 计量 MSA**：%GRR=28% → 边缘，须 **改进量具/夹具/方法** 后再建 SPC 控制限；ndc<5 时区分能力不可靠。
  • **P0 · 属性 MSA**：AOI 误判会同时伤害 Analyze（假根因）与 Control（假报警）；Kappa≥0.75 方可接受（行业惯例，以 CSR 为准）。
  • **P1 · SL/MP 分层**：X-Ray Safe Launch 100% 与量产抽检数据 **禁止混算 GRR/Cpk**。

E课堂练习（先作答再对答案）

  • E1. 解读 spi-msa.csv：%GRR 是否可接受
    参考答案

    要点：spi-msa：%GRR≈18% → Accept（<10% 理想，10–30% 边缘需改进计划）；ndc≥5 方可区分零件变差。

    以 Minitab 报告 %研究变异(RR) 行为准。

  • E2. 说明：为何不对 FCT 通过率做 Cpk
    参考答案

    要点：FCT 一次通过率是合格/不合格属性，用 p/np 图监控；Cpk 仅用于 SPI 体积、空洞% 等计量 CTQ。

    客户审计常查此混用。

  • E3. 列出车身手插通断检 MSA 计划一行
    参考答案

    要点：车身手插通断检 MSA：3 操作员×10 板×2 次，响应通/断；目标 Kappa/一致率≥0.9，记录治具号。

    与 ADAS SPI GRR 分开研究。

  • E4. 解读 RR=18% 结论
    参考答案

    要点：%RR=18%：测量系统可接受，可报告 SPI Cpk（须附 GRR 摘要）；ndc 不足则先改量具分辨力。

    18% 在 10–30% 边缘区，建议持续改进。

  • E5. Cp高Cpk低说明什么
    参考答案

    要点：Cp 高 Cpk 低：变异宽度尚可但均值偏离目标（钢网厚度/刮刀/压力）；对策调中心而非仅缩公差。

    与 FCT 程序错误、离线烧录版本无关时需分 CTQ 查。
