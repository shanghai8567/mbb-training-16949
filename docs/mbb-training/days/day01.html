B核心概念与理论框架

六西格玛是以数据减少变异、以项目创造财务结果的管理系统。DMAIC 改良现有流程；DFSS 设计新流程。

【汽车电子 · 战略 + 五产品四段工艺地图】汽车电子 EMS 的黑带项目必须按「产品 × 工艺段」建基线：离线烧录错版在 SMT 前就应拦截；BGA 空洞在 SMT/X-Ray 段度量；车身与 ADAS 的 FCT 禁止混批统计。

专业类比 — 黑带找漏水段；MBB 设计全市管网检修标准并向市长证明预算。

σ 水平是目标语言；1.5σ 偏移是行业惯例，教学时须说明与纯统计含义差异。

关键公式
DPMO = (缺陷数 ÷ (单位数×机会数)) × 10⁶

E课堂练习（先作答再对答案）

  • E1. 在 process-routing 表标出：贵司三条现场规则（SMT前离线 / X-Ray SL·MP / 车身独立 FCT）
    参考答案

    要点：routing 表标注：① 离线@SMT前 + Checksum；② X-Ray SL 100% / MP 抽检 + 切换日；③ 车身 FCT-DCU-B-04 与 ADAS FCT-05 分线。

    三条规则须与 site-config 问卷及 B+ 表一致，不可写「加强管理」。

  • E2. 用 SIPOC 画 ADAS 域控：供应商料 → 离线 → SMT → FCT → OEM
    参考答案

    要点：SIPOC：供料 → 离线烧录 → SMT(SPI/AOI) → X-Ray → FCT-05 → OEM；范围止于 EMS 出厂测试。

    Supplier/Input 要含 Program_ID、Profile#；Output 为 FCT 合格板。

  • E3. 说明：为何 FCT 良率不能用 Cpk（应用 p 图）
    参考答案

    要点：FCT 一次通过率是属性数据（合格/不合格），应使用 p 图或 np 图；Cpk 用于计量型 CTQ（如 SPI 体积、空洞%）。

    混用会导致阶段门证据被 MBB 打回。

  • E4. 用一句话区分 BB 与 MBB 时间分配差异
    参考答案

    要点：BB 约 70% 时间做 DMAIC 分析与工具；MBB 约 50% 部署/辅导/阶段门，30% 组合管理，≤20% 亲自做分析。

    MBB 不代做 Minitab，只教练与评审证据链。

  • E5. 列出 Define 阶段门必过的 3 项证据
    参考答案

    要点：Define 门：① 签字章程（问题陈述可测量）② SIPOC/范围 ③ CTQ 操作定义草案 + Champion 承诺。

    缺任一项应 No-Go 或条件通过。

Q5 【纠错】SPI Cpk=1.9 能否证明 ADAS Eth FCT 一定合格？

✓ 否；须 CTQ 对齐、MSA 合格，且 FCT 用 p 图/缺陷矩阵链到离线/BGA

精编解析

考点 纠错 — Cpk 不能代表 FCT 客户体验

正解（B） SPI Cpk 只说明焊膏体积能力；Eth FCT 为属性 CTQ，须独立 MSA + p 图 + 缺陷矩阵链到离线/BGA。

误选简析

  • A 能；Cpk>1.33 即客户满意
    见题干干扰项设计。
  • C 能；SPI 只管焊膏，与软件版本无关
    SPI 与软件版本、探针无关是错误因果。
  • D 能；忽略 X-Ray 阶段
    X-Ray 阶段必须纳入 Analyze 分层。
