    结构工程师加散热鳍片够不够？

    专业加深（P0 / P1）
    • **P1 · ASIL 边界**：EMS 可负责 **出厂可测 CTQ**（Eth 环回、Checksum）；**整车感知时延/ASIL 分解** 需 OEM 接口，勿写进 EMS PFMEA 当唯一责任。
    • **P0 · QFD 纪律**：多人评分、关联强度需证据（仿真/试验），非一人拍脑袋。

    E课堂练习（先作答再对答案）

    • E1. 质量屋 1 个 WHAT→HOW（如时延→镜像/Profile）
      参考答案

      要点：WHAT→HOW：OEM 启动时延 → HOW：SOC 镜像版本 + Profile# + FCT 脚本；屋顶：镜像版本与 Profile 强正相关。

      EMS 验证止于 FCT；整车时延 OEM 测。

    • E2. 界定 EMS vs OEM 验证边界
      参考答案

      要点：EMS：SPI/FCT/Checksum/AXI；OEM：整车 Eth 路试、功能安全确认、OTA — 质量屋 HOW 不越界写 OEM 责任。

      接口 CTQ 在合同中界定。

    • E3. 列 3 VOC
      参考答案

      要点：VOC 原话 3 条：① Eth 丢包投诉 ② 启动>8s ③ 夜间 CAN 休眠异常 — 转可测 CTQ。

      勿直接写解决方案。

    • E4. 画屋顶一对相关
      参考答案

      要点：屋顶：Profile# 与钢网厚度 ○ 正相关；冷却斜率与空洞% △ 负相关（示意一对即可）。

      团队共识打分，非一人填。
