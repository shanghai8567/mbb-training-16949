    B核心概念与理论框架

    控制图是心电图；出界先查测量与规程。

    【汽车电子 · Control — 五产品控制计划】控制计划反应计划须写清：错版→停线隔离；SPI 低→停线清钢网；空洞超→复测 X-Ray；FCT 跌→追溯烧录+Profile。

    专业类比 — I-MR 像每日体检；Xbar-R 像每组抽检。

    子组 n=1 用 I-MR；缺陷率用 p 图。

    E课堂练习（先作答再对答案）

    • E1. control-plan 标 ADAS X-Ray 切换条件
      参考答案

      要点：control-plan：ADAS X-Ray 行注明 SL 100% / MP 抽检% + 切换日期 + 反应（升级 SL）；DCU-B 手插通断 100%。

      与 pfmea-electronics 探测一致。

    • E2. 车身 DCU-B 手插+ FCT-04 各 1 行
      参考答案

      要点：车身：手插浮高 → 通断检；FCT-04 → Eth/CAN 项；各 1 行含规格、频次、反应、负责人。

      工站号不得写错 FCT-05。

    • E3. 选 I-MR 还是 Xbar-R
      参考答案

      要点：n=1 子组/慢节拍 → I-MR；n=4–5 子组快节拍 → Xbar-R；缺陷率 → p 图。

      改进前后须阶段分隔。

    • E4. 写反应计划
      参考答案

      要点：反应计划：Western 规则 1 点出界 → 查 MS → 查 Profile# → 通知 BB；连续 8 点同侧 → 查原材料批次。

      操作员可执行、可培训。
